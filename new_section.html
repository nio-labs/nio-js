4. Project Scaffolding (Add-on)

You can optionally scaffold a new full-stack project or mobile app using the interactive initialization tool:

nio-js init

This auto-generates a wired frontend (Vue, React, Svelte, etc.) and a NioJS backend with native tasks. You can run it interactively, or pass flags to skip prompts:

Option Description
-n, --name <NAME> The project directory name.
-f, --framework <FW> The frontend framework (e.g., React, Vue, Svelte, Lit, Vanilla, Blank).
-d, --db <DB> Database selection (e.g., nio-db or None).
-a, --ai <AI> AI integration (e.g., NioAI or None).

Example one-liner for a full React web app:

nio-js init web --name my-app --framework React --db nio-db --ai NioAI
